音量增强1× 不改变信号，是默认值；往上会把本来就接近满刻度的语音推过软限幅，声音变「炸」
窄带增强（2.6 kHz）把语音的清晰度提一点。DMR 只有 8 kHz 带宽，辅音本来偏闷； 但如果手机喇叭听着「噼啪」「发刺」，先关掉它对比一下 —— 这一档会在 2.6 kHz 抬高 2.5 dB，小喇叭最容易被这一点推破音。

实验性
收发都走 MMDVM / Homebrew（UDP 62031），和收听用的 HOSE 是两条独立链路。 主站地址、DMR ID、密码这些参数就在下面的「⚙️ 主站与身份」里填 —— 原来在对讲页，现在统一收到设置里；对讲页顶部只留一条快捷身份栏。
登录 ID = DMR ID（+ ESSID 别名 ID）。「ESSID 别名 ID」默认就是 0（不用别名）， 登录 ID 是 7 位，和 Pi-Star / DroidStar 的 ESSID = None 完全一样 —— 绝大多数情况就该保持 0。只有当你在 SelfCare 里额外登记过一台带别名的热点时， 才把这一项选成 01~99（登录 ID 变成 9 位）， 用来和另一台 Pi-Star / openSPOT 同时在线。
最容易踩的坑：SelfCare 里只登记了裸 ID，却把这一项选了 01 —— 登录 ID 变成 461418701 这种主站根本不认识的号，密码那步能过， 但主站在下发配置那步查不到记录，必然回 MSTNAK。 连续被拒到上限时，发射条会显示「因技术问题，DMR 发射暂不开放」—— 收听与录音不受影响。
国内网络另有一套规则：DMR ID 用 86 开头（在 radiowo.com 注册审核）， 密码是 radiowo 后台给这台热点设的热点密码，主站是 8600.radiowo.com（端口 62031）。 首次发射前要先在 860.radiowo.com/dmrdevices 登记本机， 否则主站会在登录阶段直接回 MSTNAK。

⚙️ 主站与身份 ▸

主站地址怎么填 —— 这里要的是 Master（主站），不是收听用的 hose.brandmeister.network。命名规则是 <主站ID>.master.brandmeister.network， 主站 ID 取自官方主站表 api.brandmeister.network/v2/master。
  • 4602.master.brandmeister.network · 中国（43.129.83.124），推荐（已预填）
  • 4501 韩国 · 5021 马来西亚 · 5051 澳大利亚（依次备选）
点主站地址右边那个 ▾ 展开选择面板：里面分「🇨🇳 国内 China DMR」和 「🌍 国际 BrandMeister」两组，共 40+ 台，带搜索框，每条都标了 :62031 —— 页面加载时从官方主站表自动生成，不用手记。 注意两个不存在的地址：4601.master.brandmeister.network 和裸的 master.brandmeister.network 都解析不了（前者 NXDOMAIN， 后者没有 A 记录），中国区目前只有 4602 一台主站。
端口固定 62031（UDP），协议是 MMDVM / Homebrew，和收听用的 HOSE 是两条独立链路。
密码必须是 SelfCare 里的「热点安全密码」，不是登录密码， 并且要先把你的 DMR ID 在 SelfCare 里登记为热点。
呼号要与 DMR ID 的注册信息一致（官方排障页明确要求）， 大小写、数字 0 与字母 O、数字 1 与字母 l 都容易填错。 从别处复制密码时特别容易带上首尾空格，App 会自动去掉并在日志里提示。
「ESSID 别名 ID」怎么填 —— 这是最容易填错、也最容易卡住登录的一项。 默认选 0（不用别名）就是对的。Pi-Star、DroidStar、BlueDV 这一项默认都是 None，SelfCare 里绝大多数人也只登记了裸 DMR ID 那一台热点。 这一项填 0 时登录 ID 是 7 位（4614187），和那些客户端完全一致。
什么时候才需要填 01~99：你已经有一台 Pi-Star / openSPOT / BlueDV 在用同一个 DMR ID，而且想让它和本 App 同时在线。这时给本机配一个别名 （4614187 + 06 → 461418706，9 位）， 在主站眼里就是一台独立热点。官方原文：「Each hotspot must have a unique ID and ESSIDs allow for this to work properly on the network.」
⚠ 别把这两件事搞反：别名不是"随便填一个就能连"的万能药。 主站在下发配置那一步会查这个 9 位 ID 有没有登记过； 没登记就是「密码过了、配置被拒」，表现正是 MSTNAK + 停在 CONF 步。 判断办法：拿那台能连上的客户端看一眼它的 ESSID —— 显示 None 就把本 App 也设成 0；显示 01 就设成同一个值。
如果还是被拒：App 会自己按 10 / 20 / 40 / 60 秒逐档等待重试（累计约两分钟）， 不用反复点；状态行会写明用的是哪个登录 ID、卡在握手哪一步。 最终仍失败，先关掉其它用同一 ID 的设备，再按日志末尾那份清单逐条查。
话组参考：46001 中国全国组（周六 20:00 点名）、 46020 广东组（每晚点名）、46010 北京、 46021 上海、9 本地、91 世界组。
想确认发射到底通没通：把「呼叫类型」改成私呼， 目标填 460997（BrandMeister 的 Parrot 回声测试）， 按住 PTT 说一句话再松开，几秒后会把你的声音原样回放给你 —— 听到回放就说明发射链路完全打通了。

注意事项
  1. 62031 是 UDP，不是 TCP。防火墙 / 路由器只放行 TCP，照样连不上 —— 自建网络排查时先看这一条。
  2. 端口不是猜的。公共主站固定 62031，填错不会有任何明确报错， 症状是「握手包发出去了，一个 RPTACK 都没回来」，或者反复 MSTNAK。
  3. 端口和密码、ESSID 无关。登录被拒先查 SelfCare 里的「热点安全密码」 和「ESSID 别名 ID」，别反复改端口 —— 改端口治不了密码错。
  4. 手机流量、公司 / 校园 Wi-Fi 常封 UDP 高端口。表现是握手阶段完全没回应。 换一个 Wi-Fi 或换运营商热点再试，能连上就说明是网络环境挡的。
  5. 切网络时端口会自动回到 62031。国际 BM 和国内 radiowo 用的是同一个端口， 正常情况下根本不用手改这一项。
  6. 改完端口要「断开 → 重新连接」才生效。正在登录或已连接时改端口， App 不会自己重连。
  7. 只有自建 HBLink / 中继才需要动端口；连公共主站时这一项永远是 62031。

🎙 发射（说给对方）

麦克风增益在自动电平的基础上再抬或压。自动电平先把声音拉到固定响度， 这一档是你自己的口味 —— 觉得对方听着小声就往右，觉得发炸就往左。 往左不只是变小声，是真的少失真（增益在限幅之前）
0 dB
发射电平本次发射的峰值电平（dBFS），每按一次 PTT 重新起算。 −18 附近是正常，超过 −6 就贴着满量程了
—
增益作用在自动电平之后、软限幅之前 —— 放在自动电平前面会被它原样抵消， 你会觉得「调了没反应」；放在软限幅后面则只能把已经失真的声音调小，毛刺一个不少。
往右调太多会触发软限幅：不会硬削出方波，但声音会变「平」， 对方听上去就是「一直很响、没有起伏」。−6 ~ +6 dB 是比较安全的区间。
如果已经拉到 −24 dB 对方还说炸，问题多半不在这一级 —— 看松手后的发射小结：采集削波高是手机话筒本身过载（离远点）， 限幅高才是我们这边太激进。

🖐 PTT 按钮

PTT 可拖动开启后整颗钮能拖到屏幕任意位置，位置自动保存；关闭则回到右下角默认位
停放位置右下角（默认）
PTT 默认悬浮在右下角，列表再长也按得到。拖动用的是「按住后移动超过 6px 才判定为拖动」的判定：点按发一段短发射，长按边说边拖不动它， 拖动则挪位置不发射 —— 三种手势互不打架。
选了点击切换时，拖动和「点按发短句」都不生效（点一下就是开/关）， 因为两种手势会互相误触 —— 那时按钮固定在右下角。
关掉开关或点「重置位置」都会让它回到右下角默认位。

信标 DMR 收听台 —— 支持两套 DMR 网络，在「收听」页顶部一键切换：
· 国际 BrandMeister：收听走 HOSE（hose.brandmeister.network）， 通联走 MMDVM / Homebrew（<主站ID>.master.brandmeister.network:62031）。

通联功能声明 —— 收听、看板、录音、话组库等功能不受通联影响， 始终可用。通联属于实验性功能：它要求主站接受本机作为一台热点登录， 而 BrandMeister 对一个 DMR ID 只允许一台热点在线。 如果这个 ID 上已经有别的热点（Pi-Star / openSPOT / BlueDV 等）， 本机必须配一个 01~99 的 ESSID 别名 ID 才能与之并存，否则登录会被连续拒绝（MSTNAK）。 连续被拒到上限时，对讲页顶部会明确显示 「因技术问题，DMR 发射暂不开放」，并在「📡 对讲」页给出原因与排查步骤 —— 届时请改用其它设备发射，本 App 继续用于收听。
