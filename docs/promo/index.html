📚 知识库
常见问题与
实用知识
新手入门、术语解释、故障排除——你想知道的都在这里。
什么是 DMR？和模拟电台有什么区别？›
DMR（Digital Mobile Radio）是数字移动无线电标准。与模拟电台相比，DMR 采用数字编码，音质更清晰（无噪音），频谱效率更高（一个信道两路通话），支持数据传输、个呼、组呼、短信等丰富功能。目前业余无线电界主流的数字模式之一。
什么是 TalkGroup（话组）？›
TalkGroup（TG）是 DMR 里的「群组」概念。同一个话组内的用户可以互相通话。每个话组有一个编号（如 91 是世界组）。订阅某个话组就能听到该组的通话，也可以按住 PTT 在该组发射。
什么是个呼（Private Call）？›
个呼是 DMR 里的「一对一私聊」。输入对方的 7 位 DMR ID 进行呼叫，只有对方能听到。组呼是一对多（所有订阅该话组的人都能听到），个呼是一对一。在 Beacon-DMR 里，7 位数字自动识别为个呼。
没有业余无线电执照可以用吗？›
收听不需要执照，任何人都可以收听业余无线电通话。但发射（PTT）需要持有有效的业余无线电操作证，并在核准的频率和功率范围内操作。建议新手先收听学习，考取执照后再发射。
如何获取 DMR ID？›
在 radioid.net 注册并申请 DMR ID。需要提供呼号和操作证信息。审核通过后会分配一个全球唯一的 7 位数字 ID。中国用户也可以在国内 DMR 平台注册。
Beacon-DMR 支持哪些 Android 版本？›
最低支持 Android 8.0（API 26）。建议 Android 10 以上以获得最佳体验。App 体积仅约 2.3 MB，对设备性能要求极低。
什么是 FMO 中继？湖北 FMO 是什么？›
FMO（Frequency Modulation Operation）是一种数字业余无线电中继制式。湖北 FMO 中继已接入 OpenRF、RLlink、HT 三大链路，实现多协议互通。你可以通过 Beacon-DMR 或 OpenRF 客户端接入湖北 FMO 中继进行通联。
PTT 对讲怎么用？›
先在话组库或实时活动里选择一个话组（或个呼目标），然后按住右下角的 PTT 按钮说话，松开结束发射。发射前确保已连接到网络（设置里配置好热点参数）。说话时注意不要按住时间过长，留出间隙给其他人插入。
