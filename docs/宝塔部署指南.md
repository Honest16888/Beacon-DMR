# 宝塔面板部署 Beacon-DMR 更新推送系统

## 一、准备文件

把这 3 样东西上传到服务器：

```
/root/update/
├── update_server.py     ← 更新服务端脚本
├── apks/                ← APK 目录
│   └── beacon-dmr-2.10.1-release.apk
└── manifest.json        ← 服务端自动生成（不用手动建）
```

**上传方式**（宝塔面板）：
1. 打开宝塔 → 文件 → 进入 `/root/`
2. 新建文件夹 `update`
3. 进入 `update`，新建文件夹 `apks`
4. 上传 `update_server.py` 到 `/root/update/`
5. 上传 APK 到 `/root/update/apks/`

## 二、安装 Python（如果没装）

宝塔 → 终端：

```bash
python3 --version
# 如果没有：
apt install python3 -y     # Ubuntu/Debian
yum install python3 -y     # CentOS
```

不需要装任何第三方库，脚本只用标准库。

## 三、启动服务

宝塔 → 终端：

```bash
cd /root/update
python3 update_server.py --port 8080 --apk-dir ./apks &
```

测试：
```bash
curl http://127.0.0.1:8080/api/version?current=2.10.0
```

应该返回 JSON。

## 四、设置开机自启（systemd）

宝塔 → 终端：

```bash
cat > /etc/systemd/system/dmr-update.service << 'EOF'
[Unit]
Description=Beacon-DMR Update Server
After=network.target

[Service]
Type=simple
ExecStart=/usr/bin/python3 /root/update/update_server.py --port 8080 --apk-dir /root/update/apks
WorkingDirectory=/root/update
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable dmr-update
systemctl start dmr-update
systemctl status dmr-update
```

## 五、宝塔建网站 + Nginx 反代

### 方法 A：纯 HTTP（最简单）

宝塔 → 网站 → 添加站点：

1. 域名填 `update.你的域名.com`（或直接填服务器 IP）
2. PHP 版本选「纯静态」
3. 提交

然后点网站名 → 反向代理 → 添加反向代理：

- 代理名称：`update`
- 目标 URL：`http://127.0.0.1:8080`
- 发送域名：`$host`

保存即可。

### 方法 B：HTTPS（推荐）

1. 先按方法 A 建好站点和反代
2. 点网站名 → SSL → Let's Encrypt → 勾选域名 → 申请
3. 开启「强制 HTTPS」

http://update.你的域名.com/

设置 → 更新服务器 → http://update.你的域名.com

## 七、发布新版本

```bash
# 1. 本地构建
bash tools/build_apk.sh release

# 2. 上传 APK 到服务器
#    宝塔文件管理器 → /root/update/apks/ → 上传

# 3. 没了——服务端自动识别新 APK
```

编辑 `manifest.json` 可以加更新说明：

```json
{
  "versions": {
    "2.10.1": {
      "changelog": "修：AURA 账号自检 + WebSocket",
      "force": false
    }
  }
}
```

## 八、防火墙

宝塔 → 安全 → 放行端口：

| 端口 | 用途 |
|---|---|
| 8080 | 更新服务（如果不用 Nginx 反代） |
| 80 | HTTP（Nginx） |
| 443 | HTTPS（Nginx） |

如果用了 Nginx 反代，8080 可以不放行（只监听 127.0.0.1）。

## 常见问题

**Q: 服务启动就退出？**
```bash
journalctl -u dmr-update -f
# 看日志找原因
```

**Q: App 检查更新失败？**
```bash
curl http://update.你的域名.com/api/version?current=2.10.0
# 浏览器能不能打开？
```

**Q: 怎么加强制更新？**
编辑 `manifest.json`，把对应版本的 `"force": false` 改成 `"force": true`。

**Q: 能限制只有我能下载吗？**
Nginx 反代配置里加 Basic Auth：
```nginx
location / {
    auth_basic "Restricted";
    auth_basic_user_file /root/update/.htpasswd;
    proxy_pass http://127.0.0.1:8080;
}
```
生成密码文件：
```bash
htpasswd -c /root/update/.htpasswd 你的用户名
```
